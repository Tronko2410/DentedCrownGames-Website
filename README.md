# DentedCrownGames-Website
Official website of Dented Crown Games — https://dentedcrowngames.com

Plain static HTML/CSS/JS, hosted on GitHub Pages. Every push to `main` goes live in about a minute.

- `index.html`, `games/`, `about/`, `contact/`, `imprint/`, `privacy/`, `404.html` — pages
- `games/all-in-debt/` — All in Debt! page (uses the `.theme-aid` casino colors)
- `assets/css/style.css` — all styles; brand colors are CSS variables at the top
- `assets/js/main.js` — mobile menu, scroll reveals, crown easter egg, debt counter
- `assets/fonts/` — self-hosted Archivo Black + Inter (SIL Open Font License)
